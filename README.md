# Rule-Based AI: Car Evaluation Classification

## Overview
Two rule-based classifiers for UCI Car Evaluation Dataset:
- **Flat System**: Sequential independent rules
- **Hierarchical System**: Nested, DEX-inspired logic

## Files
- `car.data` – Dataset
- `main.py` – Run experiments
- `flat_classifier.py` – Flat rules
- `hierarchical_classifier.py` – Hierarchical rules

## Run
```bash
python main.py
